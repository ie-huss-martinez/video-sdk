The package now depends on `@hussmartinez/ui` ^0.11.0 and `@hussmartinez/sdk-core` ^0.4.4, up from ^0.7.0 and ^0.4.3. Nothing in the editor changes yet: this brings in ui's `Timeline` and its `hm-text` class, which later releases use. An application that installs `@hussmartinez/ui` itself, for its stylesheet or its components, should move to 0.11 too, so it has one copy.
