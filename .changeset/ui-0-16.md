Requires `@hussmartinez/ui` 0.16.0 or later, the version the family's editors now share. ui 0.16.0 adds heading levels (`HeadingLevel`, `Heading`) for editors that sit in someone else's page. The video editor renders no headings, so nothing changes in what it shows, and it has no `headingLevel` prop. If your app also depends on `@hussmartinez/ui`, update it to ^0.16.0, so there's one copy.
